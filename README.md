## Hi, I'm Ravi Kapadia 👋

**QA Automation Engineer** at DevRepublic India · Ahmedabad, India · ISTQB® CTFL

- Migrating legacy Cypress suites to Playwright
- API testing and data-driven tests (JSON, CSV, Excel)
- CI/CD pipelines in Azure DevOps, with test management and reporting in Zephyr Scale
- Web application security testing with OWASP ZAP
